# Анализ количественных данных в социальных науках

Домашнее задание: влияние возраста, образования, места проживания и социального положения на финансовое поведение населения.

**Данные:** опрос Банка России о финансовом поведении населения, 2022 г. (12 162 респондента, 32 региона).

**Методы:** таблицы сопряжённости, критерий хи-квадрат, V Крамера, коэффициенты корреляции Пирсона, Спирмена, Кендалла и точечно-бисериальный.
